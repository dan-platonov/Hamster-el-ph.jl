# Supplied PERTURBO reference curve

The CSV is the two-column export previously made from the user's supplied
GaAs PERTURBO validation plot, gaas_g2_sum_all_phonon_modes.png. It is used as
reference data, not regenerated by this repository. x is the original cumulative
L-Gamma-X-W-K-Gamma path coordinate; y is the all-phonon-mode sum in meV^2 for
the reference electronic band and initial Gamma convention.

The source plotting script was named plot_perturbo_g2_sum_all_modes_v1.py.
The underlying Perturbo simulation inputs and external software are not bundled.

## Source attribution

The project author identifies the following PERTURBO documentation page as the
source of the reference:

[PERTURBO: Interface to TDEP and SSCHA](https://perturbo-code.github.io/mydoc_tdep.html).

The linked page describes the TDEP/SSCHA interfaces and a SrTiO3 example; it does
not directly show this GaAs comparison curve or its CSV. The link is recorded as
the author-supplied source attribution. The numerical reference in this
repository remains the previously supplied GaAs export described above; its
exact downloadable dataset is not independently identified by that page.
